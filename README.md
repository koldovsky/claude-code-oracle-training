## Про курс

Дві практичні сесії по дві години для Oracle-розробників: як працювати з
Claude Code так, щоб він був корисним на великій системі, а не лише на
навчальному прикладі.

**Сесія 1** — модель роботи інструмента, налаштування й безпека,
контекст-інжиніринг для Oracle, підключення до бази через MCP.
Дві вправи руками, обидві з перевіркою результату проти незалежного джерела.

**Сесія 2** — skills, subagents, hooks, spec-driven development.

## Шпаргалка

Усі команди й промпти заняття з кнопкою «копіювати», під кожною — що саме
має з'явитися на екрані. Значення, які підставляє учасник, позначені
ВЕЛИКИМИ ЛІТЕРАМИ: сервіс бази, логін, пароль, шлях до wallet.

## Запустити слайди локально

```bash
npm install
npm start
```

`p` — режим доповідача з нотатками, `f` — на весь екран.
